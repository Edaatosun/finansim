# Finansım

Aylık bütçe, gelir/gider ve birikim takibi. Üyelik yok; tüm veriler kullandığın cihazın tarayıcısında (localStorage) saklanır, hiçbir sunucuya gönderilmez. Kodda kişisel veri yoktur.

## Kullanım
- **İnternetten:** GitHub Pages adresini iPhone Safari'de aç → Paylaş → **Ana Ekrana Ekle**.
- **Yerelde:** `Finansım Başlat.command` dosyasına çift tıkla → http://localhost:8080

## Sayfalar
- **Özet:** kalan para, gelirlerim kartı, sabit giderlerim (Öde düğmesi), kategorilerim (ekle/düzenle/sil), ay sonu kâr-zarar analizi, başarı puanı.
- **Giriş / Çıkış:** kategori seç → ayrılan / harcanan / kalan ve o ayki hareketler; gider (taksitli olabilir) ve gelir girişi.
- **Rapor:** aylık planlanan-harcanan grafiği, finansal başarı tablosu, gelecek taksit yükü, kategori karnesi.
- **Birikim:** altın/döviz/TL varlıkları canlı kurla (Harem Altın), kâr/zarar, hedefler.
- **Ayarlar:** ad, tema, PIN kilidi, yedek al/yükle, veri kodu.

Kur kaynağı: Harem Altın (yedek: Truncgil, gold-api.com + frankfurter.dev).
